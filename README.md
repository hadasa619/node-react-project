# מערכת מכירה סינית

## תיאור הפרויקט

מערכת מכירה סינית היא אפליקציה מלאה (Full-Stack) המאפשרת ניהול מוצרים, עגלות קניות, אימות משתמשים וניהול חשבונות. הפרויקט כולל צד לקוח מבוסס React וצד שרת מבוסס Node.js.

הפרויקט מתקשר עם API שנמצא בכתובת: [https://github.com/hadasa619/ChineseRaffleApi](https://github.com/hadasa619/ChineseRaffleApi)

## טכנולוגיות המשמשות

### צד הלקוח (Frontend)
- **React**: ספריית JavaScript לבניית ממשקי משתמש
- **Redux Toolkit**: לניהול מצב האפליקציה
- **Axios**: לספריית HTTP לקריאות API
- **PrimeReact**: ספריית רכיבי UI
- **React Router DOM**: לניווט בין דפים
- **CSS Modules**: לניהול סגנונות

### צד השרת (Backend)
- **Node.js**: סביבת זמן ריצה ל-JavaScript בצד השרת
- **Express**: מסגרת אפליקציות אינטרנט ל-Node.js
- **Mongoose**: ODM ל-MongoDB
- **JWT (JSON Web Tokens)**: לאימות משתמשים
- **bcrypt**: להצפנת סיסמאות
- **CORS**: לטיפול בבקשות חוצות מקורות

## הוראות הרצה

### דרישות מקדימות
- Node.js (גרסה 14 ומעלה)
- npm או yarn
- MongoDB (או חיבור למסד נתונים מרחוק)

### התקנת תלויות והרצה

#### צד הלקוח
1. נווט לתיקיית הלקוח:
   ```
   cd client
   ```

2. התקן את התלויות:
   ```
   npm install
   ```

3. הרץ את האפליקציה במצב פיתוח:
   ```
   npm start
   ```
   האפליקציה תרוץ בכתובת `http://localhost:3000`

#### צד השרת
1. נווט לתיקיית השרת:
   ```
   cd server
   ```

2. התקן את התלויות:
   ```
   npm install
   ```

3. הרץ את השרת במצב פיתוח (עם nodemon):
   ```
   npm run dev
   ```
   או במצב ייצור:
   ```
   npm start
   ```
   השרת ירוץ בכתובת `http://localhost:5000` (או לפי ההגדרות)

### בניית הפרויקט לייצור
לצד הלקוח:
```
cd client
npm run build
```
זה ייצור תיקיית `build` עם הקבצים המוכנים לייצור.
